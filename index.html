Section 1

Introduction to Routing

+

What is Routing?

Routing is the process of selecting a path for traffic in a network. A router examines the destination IP address of each packet and forwards the packet to the next hop on the best path toward that destination.

Routing happens at Layer 3 of the OSI model, the Network Layer.

Static vs Dynamic Routing

  • Static routing: routes are configured manually by an administrator. They do not change unless the administrator changes them.
  • Dynamic routing: routes are learned automatically from other routers using a routing protocol. Routers exchange information and adapt to changes.

Autonomous System (AS)

An Autonomous System is a group of networks under a single administrative control, such as one company or one Internet Service Provider.

  • Interior Gateway Protocols (IGP): used inside one AS. Examples: RIP, OSPF, EIGRP, IS-IS.
  • Exterior Gateway Protocols (EGP): used between different autonomous systems. Example: BGP.

Route Selection Order

When a router has multiple routes to the same destination, it chooses in this order:

  • Longest prefix match: the most specific route wins, for example /24 beats /16.
  • Lowest administrative distance: when the prefix length is the same, the protocol with the lowest AD wins.
  • Lowest metric: when AD is the same, the route with the lowest metric wins.
Section 2

Distance Vector Routing Protocols

+

What is a Distance Vector Protocol?

A distance vector protocol shares its entire routing table with its directly connected neighbors at regular intervals. It measures distance as a metric and chooses the path with the smallest distance.

The best known example is RIP, which uses the Bellman-Ford algorithm.

RIP: Routing Information Protocol

  • Metric is hop count.
  • Maximum valid hop count is 15. A count of 16 means unreachable.
  • RIPv1 is classful and does not carry subnet masks. RIPv2 is classless and supports VLSM and CIDR.
  • Administrative distance is 120.
  • Uses split horizon, route poisoning, and hold-down timers to prevent loops.
  • Default timers: Update 30 seconds, Invalid 180 seconds, Hold-down 180 seconds, Flush 240 seconds.

Problems with Distance Vector Protocols

  • Routing loops: packets bounce between routers.
  • Count to infinity: the hop count keeps increasing instead of stopping.
  • Slow convergence: the network takes a long time to agree on a new topology.

Fixes include split horizon, route poisoning, hold-down timers, and triggered updates.

Section 3

Link State Routing Protocols

+

What is a Link State Protocol?

A link state protocol builds a complete map of the network topology. Every router knows the state of every link. It uses the Dijkstra Shortest Path First algorithm to calculate the best path.

The best known example is OSPF.

OSPF: Open Shortest Path First

  • Metric is cost, calculated as reference bandwidth divided by interface bandwidth. Default reference is 100 Mbps.
  • Administrative distance is 110.
  • Open standard, works with any vendor.
  • Supports VLSM and CIDR.
  • Converges very fast using triggered updates and the SPF algorithm.
  • Uses areas to make the network more scalable. Area 0 is the backbone.
  • Default hello timer is 10 seconds and dead timer is 40 seconds on broadcast networks.

OSPF LSA Types

  • Type 1: Router LSA. Every router generates one.
  • Type 2: Network LSA. Generated by the designated router.
  • Type 3: Summary LSA. Generated by Area Border Routers to share routes between areas.
  • Type 5: External LSA. Routes redistributed from outside OSPF.

OSPF Router Roles

  • Internal router: all interfaces are in one area.
  • Backbone router: has an interface in area 0.
  • Area Border Router (ABR): connects two or more areas.
  • Autonomous System Boundary Router (ASBR): connects OSPF to another routing domain.
Section 4

EIGRP and BGP

+

EIGRP: Enhanced Interior Gateway Routing Protocol

  • Advanced distance vector, also called hybrid.
  • Cisco proprietary.
  • Metric is a composite of bandwidth, delay, load, and reliability. MTU is used only for path selection.
  • Administrative distance is 90 for internal routes and 170 for external routes.
  • Uses the DUAL algorithm. Very fast convergence.
  • Supports unequal cost load balancing with the variance command.
  • Hello timer is 5 seconds and hold timer is 15 seconds on fast links.

BGP: Border Gateway Protocol

  • Path vector protocol.
  • Used between autonomous systems on the Internet.
  • Administrative distance is 20 for external BGP and 200 for internal BGP.
  • Uses path attributes such as AS path, local preference, multi exit discriminator (MED), and weight.
  • Prevents loops by checking the AS path. If a router sees its own AS in the path, it rejects the route.
  • Uses TCP port 179 for transport.

Section 6

VLSM: Variable Length Subnet Masking

+

What is VLSM?

VLSM stands for Variable Length Subnet Masking. It allows a network to be divided into subnets of different sizes. A large subnet can serve a large department while a small subnet serves a point to point link between two routers.

VLSM uses classless routing. It requires a routing protocol that carries the subnet mask, such as RIPv2, OSPF, EIGRP, or BGP.

Why VLSM Matters

  • Reduces wasted IP addresses.
  • Allows efficient use of a limited address block.
  • Supports hierarchical addressing and summarisation.
  • Is essential for modern networks where IPv4 addresses are scarce.

Host Formula

Usable hosts = 2^(host bits) minus 2 For /24: 2^8 minus 2 = 254 usable hosts For /30: 2^2 minus 2 = 2 usable hosts

We subtract 2 because one address is the network address and one is the broadcast address.

Steps to Perform VLSM

  • List all subnets needed with their host requirements.
  • Sort them from largest to smallest.
  • Assign the largest subnet first, using the smallest prefix that fits its hosts.
  • Continue with the next largest, using the next available block.
  • Use /30 for point to point links between routers.
  • Verify that no subnets overlap and all hosts are accommodated.

Worked Example

Given the block 192.168.10.0/24, subnet it for the following:

  • Sales: 100 hosts
  • IT: 50 hosts
  • Admin: 20 hosts
  • WAN link between two routers: 2 hosts

Step 1, sort largest to smallest: Sales 100, IT 50, Admin 20, WAN 2.

Step 2, assign:

Sales (100 hosts needs /25, 126 usable) 192.168.10.0/25 hosts 192.168.10.1 to 192.168.10.126 broadcast 192.168.10.127 IT (50 hosts needs /26, 62 usable) 192.168.10.128/26 hosts 192.168.10.129 to 192.168.10.190 broadcast 192.168.10.191 Admin (20 hosts needs /27, 30 usable) 192.168.10.192/27 hosts 192.168.10.193 to 192.168.10.222 broadcast 192.168.10.223 WAN link (2 hosts needs /30, 2 usable) 192.168.10.224/30 hosts 192.168.10.225 and 192.168.10.226 broadcast 192.168.10.227

Total used: 228 addresses out of 256. The remaining 192.168.10.228/30 through 192.168.10.252 are free for future growth.

Common VLSM Mistakes

  • Assigning a subnet that is too small and running out of host addresses.
  • Overlapping subnets because the next block was chosen incorrectly.
  • Using a classful protocol like RIPv1 which cannot carry the mask.
  • Forgetting to reserve a /30 for router to router links.
